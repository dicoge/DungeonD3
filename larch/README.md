# DungeonD3 骰子地城 — Larch 版

DungeonD3 已移植到 [Larch](https://larch.ink) 的 RPG 系統，專案名稱：**DungeonD3 骰子地城**
（Project ID `project-9b6b5d57-a39b-460d-bf29-5a7ccf434094`）。

## D20 機制怎麼保留

原版用 D20 擲出行動點數來移動，Larch RPG 是自由移動加回合制戰鬥，所以 D20 改成「命運」判定：

- **命運祭壇**（每層一座）：擲 1 → 怪物伏擊；2–6 → 回滿血；7–13 → 金幣＋魔法藥水；14–19 → 經驗值＋藥水；20 → 升一級＋鳳凰羽毛＋傳說裝備。
- **寶箱**：打開前擲 D20。1 → 寶箱怪；2–9 → 金幣；10–17 → 藥水；18–19 → 好裝備；20 → 傳說裝備。
- 其他：地面裂縫陷阱會扣血；每層有記錄石碑可存檔；守門怪物打倒後，往下的階梯才會解封。

## 數值

Larch 的傷害公式是「攻擊 − 防禦（最少 1）」，所以怪物數值依主角成長曲線（Lv1–20、HP 110→560、攻擊 14→62、防禦 4→32）重新平衡。
原始數值仍保留在 `content/*.json`。

## 美術

所有圖都來自 Kenney Tiny Dungeon（CC0）像素素材，經過重新上色與組合：

- `scripts/make_art.py`：怪物（骷髏、喪屍、魔像、惡魔、巫妖王等改色）與道具圖示（D20、金幣、卷軸、炸彈、王冠…）
- `scripts/bg.py`：每層專屬的戰鬥背景 `bg_f1`–`bg_f5`
- `scripts/cover.py`：標題畫面封面
- `art/`：產出的圖檔（`*@big.png` 為上傳到 Larch 的 8 倍放大版）

腳本需要先下載 Larch 內建的 Kenney 素材 `tiny-dungeon.png`、`cyclops.png`、`dragon-nightfall.png` 放在同一個資料夾。
