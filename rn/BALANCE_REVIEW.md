## Balance Issues

### 1. 15F Boss HP — 事實確認

```
15_boss  base_hp = 400
getFloorMultiplier(15) → 3.0
實際 HP = Math.floor(400 × 3.0) = 1200 ✅
```

**確認結果：正確。並非 800。**

但發現一個可讀性問題：

```typescript
// 宣告的常數 (從未使用)
const FLOOR_MULTIPLIER: Record<string, number> = {
  '1-3': 1.0, '4-6': 1.3, '7-9': 1.6, '10-14': 2.0, '15': 2.0,  // ← '15': 2.0 是死碼
};

// 實際作用的是獨立函式
function getFloorMultiplier(floor: number): number {
  if (floor <= 14) return 2.0;
  return 3.0;  // floor 15 實際倍率
}
```

**⚠ 嚴重等級：低（資料正確，但死碼誤導開發者）**

### 2. 道具性價比分析

| 道具 | 價格 | 效果 | 每金幣效率 | 邊際價值 |
|------|------|------|-----------|---------|
| 生命藥水 | $15 | +30 HP | **2.00 HP/$** | 核心 |
| 火球卷軸 | $25 | 35 傷害 | 1.40 dmg/$ | 策略 |
| 炸彈 | $30 | 40 傷害 | 1.33 dmg/$ | 策略 |

**純數值看：生命藥水性價比最高。**

但實際戰場不是算術題：

**傷害道具的隱藏價值：穿甲**

`useItem()` 對傷害道具的處理方式是**直接扣除血量**，完全繞過 `resolveAttack()` 的命中/防禦結算。這意味著：

- 火球卷軸 / 炸彈 → 在 floor 1-9 階段是「方便但不必要」的奢侈品
- 在 floor 10+ → 因為敵方 DEF 曲線爆炸，它們變成**唯一能穩定造成傷害的手段**

**具體推算（15F Boss，DEF = 75）：**
```
玩家攻擊命中需要的骰值：
max_possible_atk = 5(base) + 10(steel_sword) = 15
所需 d20 值 > 75 - 15 = 60 → 不可能
唯一可行：自然 20 暴擊（5%機率），傷害 = 15 + 2d6 = 17~27
一場 15F Boss 戰需要約 44~70 次暴擊，耗時 880~1400 次攻擊
```

**結論：火球卷軸 vs 炸彈的定價差異合理**（$5 換 5 傷害，公平）。但整體傷害道具被低估——它們的戰略價值遠高於面板數字。

**建議調整：**
- 炸彈 $30→$45，火球卷軸 $25→$35（現行價格抑制了商店購買動機，因為玩家很快就會發現正常攻擊打不動後期王）
- 或另設「錢→傷害」轉換機制，而不是靠便宜的消耗品硬扛

### 3. 樓層難度倍率 — 極端曲線

```
Fl    Mult     Boss(HP/ATK/DEF)      玩家基礎 ATK
─────────────────────────────────────────────
 1     1.0     —                      5
 4     1.3     —                      5 (等級進度約 Lv.1)
 5     1.3     深淵領主 390/32/13     5~7
 7     1.6     —                      7~9
10     2.0     深淵將軍 1000/70/36    11~15
14     2.0     —                      15+
15     3.0     暗黑龍王 1200/135/75   15~17+ ?
```

**⚠ 此曲線有三個致命問題：**

#### (A) 防禦曲線與攻擊曲線完全脫鉤

```
敵方 DEF 成長 (boss):  10 → 13 → 36 → 75
玩家 ATK 成長:           5 →  7 → 15 → 17

15F Boss 戰：
  玩家 hit_chance = 5% (natural 20 only)
  敵方 hit_chance = 95% (僅 natural 1 miss)
  敵方一擊傷害 = 135 + D6 = 136~141
  玩家最大 HP ≈ 30 + 10×Lv = 最大約 120~150
  → 一擊必殺
```

玩家成長完全跟不上敵方曲線。這不是「挑戰」，而是「數學上的不可能」。

#### (B) 10→15 層的陡峭度不合理

```
Floor 14: 倍率 2.0x  →  難度曲線平穩 (7-14 層玩家可以適應)
Floor 15: 倍率 3.0x  →  比前一層直接跳升 50%
          DEF 從 ~36 跳升到 ~75 (+108%)
          ATK 從 ~70 跳升到 ~135 (+93%)
```

一次跳升接近翻倍，沒有過渡區。

#### (C) 沒有防禦穿透或護甲削減機制

D20 系統最大的魅力是「運氣可以逆轉劣勢」，但在 DEF 75 面前：
- 玩家需要 d20 > 60 才能命中 → 物理上不可能
- 即使是暴擊也只靠強制命中規則生效，但傷害極低
- 這讓 D20 的存在變得無意義

## Progression Feel

| 階段 | 樓層 | 玩家感受 | 評分 |
|------|------|---------|------|
| 🟢 教學期 | 1-3 | 節奏舒服，骰子決定命運，攻擊偶爾 Miss 但有樂趣 | ★★★★ |
| 🟡 過渡期 | 4-6 | 怪物稍微變硬，$30 買炸彈還算開心，一發清場有爽感 | ★★★ |
| 🟠 壓力期 | 7-9 | 怪物變得更硬，沒裝備開始吃力。幸好多層商店有鎖子甲 | ★★ |
| 🔴 瓶頸期 | 10-14 | 防禦值開始脫鉤，普通攻擊常態 Miss，開始依賴道具。10F Boss 深淵將軍已成難關 | ★ |
| 💀 絕望期 | 15 | 暗黑龍王 DEF 75，玩家完全打不動。只能靠大量消耗品磨血 | ☆ |

**整體進程感受：前期輕快 → 後期突然撞牆。**

造成這種感受的根源不是「難」，而是**戰鬥系統的數學斷層**——玩家的成長是線性（ATK +2/Lv.），而敵方成長是多項式倍率。

## Motivation Analysis

### 正向動機（有作用的部分）

1. **骰子系統的隨機張力**：D20 的 1 / 20 結果帶來情緒波動，這是好的設計
2. **商店每 3 層出現**：提供明確的中繼目標
3. **升級帶來即時屬性提升**：HP 重置 +10 是好的獎勵循環
4. **消耗品可直接造成傷害**：這其實救了這個系統——沒有這個機制，10F 之後根本無法通關

### 削弱動機的問題

1. **成長曲線暗示失調**
   - 玩家在低層累積金幣買裝備，但在後期發現裝備加成（鋼鐵劍 +10 ATK）對抗最終 Boss 完全無用
   - 這會讓玩家覺得「前期努力白費了」

2. **Boss 戰 = 道具消耗戰**
   - 如果唯一有效打 Boss 的方法就是燒道具，這不是策略選擇，而是強制課金（雖然這裡不是真的課金，但感覺一樣差）
   - 需要的消耗品數量不切實際：15F Boss 1200 HP，炸彈一次 40 傷 → 需要 30 顆 = $900。而玩家跑完整個 game 金幣收入？

3. **D20 在後期失去意義**
   - D20 地城 RPG 的核心賣點是「骰子決定命運」
   - 當命中率只剩 5% 時，骰子不再有趣——它變成了令人沮喪的等待
   - 最佳設計是：高難度 → 玩家靠策略 + 運氣逆轉；極高難度 → 玩家靠策略克服

## Verdict: FAIL

**現行數值曲線無法支撐完整的 15 層冒險體驗。** 這不是遊戲太難的問題——而是數學層面上，10F / 15F 的正常戰鬥機制已經崩潰。

### 必須修正的問題（按優先級）

#### P0 — Blocking（無法通關）

- 敵方 DEF 成長曲線與玩家 ATK 成長脫鉤，10F Boss 起正常攻擊幾乎不可能命中
- 這導致唯一解法是消耗品海量堆疊，違背設計意圖

#### P1 — 重度問題

- 樓層 10→15 的倍率跳升（2.0→3.0）沒有任何過渡
- 15F Boss 一擊傷害（135 + D6）超過玩家最大 HP，違反「可反擊」的戰鬥設計前提

#### P2 — 可讀性

- `FLOOR_MULTIPLIER` 宣告 `'15': 2.0` 但實際從未使用，`getFloorMultiplier()` 返回 3.0

### 建議修復方向

1. **重新設計倍率曲線** — 將 10-14 層區間從 2.0 提高到 2.5，15 層維持 2.5（或 2.5），讓曲線更平滑
2. **引入防禦穿透** — 讓玩家在特定骰值下無視部分防禦（例如 d20≥15 時無視 50% DEF）
3. **裝備成長性調升** — 鐵劍 +5 → +8，鋼鐵劍 +10 → +15，鎖子甲 DEF+7 → +12
4. **Boss 專用破綻機制** — Boss 行動幾回合後露出破綻（DEF 暫時歸零），獎勵耐心而非道具海
5. **傷害道具加成曲線** — 火球卷軸 / 炸彈的傷害也隨樓層微幅提升，讓它們在後期仍然有效但不至於淪為唯一解
